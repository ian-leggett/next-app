# To-do App

A single-page to-do list. This glossary covers the language used for appearance settings.

## Language

**Theme preference**:
The visitor's chosen appearance setting: Light, Dark, or System.
_Avoid_: Color mode, skin, dark mode setting

**Light**:
A Theme preference that always shows the light appearance, regardless of the visitor's OS.

**Dark**:
A Theme preference that always shows the dark appearance, regardless of the visitor's OS.

**System**:
A Theme preference that follows the visitor's OS appearance setting. It is the default when no choice has been made.
_Avoid_: Auto, default

**Theme control**:
The on-page control the visitor uses to change their Theme preference.
_Avoid_: Theme switcher, dark mode toggle
